Detailed Description

Contains API prototypes and defines for the Clock Manager.

The Clock Manager provides services to Tasks to ensure correct interaction with features of the CLKCTRL peripheral.

◆ MW_DiagClockCfd0Begin()

errFlag_t MW_DiagClockCfd0Begin ( void )

Starts error injection diagnostic to detect faults in the Clock Failure Detection 0 (CFD0) monitor.

This function starts a CFD0 monitor diagnostic. If this function returns NO_ERROR, the diagnostic must be completed by calling MW_DiagClockCfd0End after sufficient time has elapsed.

Warning

The diagnostic configures OSC32K as the CFD0 reference clock. The CFD requires 10 reference clock cycles to complete one measurement period, but a previous measurement period may need to complete before the injected fault is detected. The calling function must therefore ensure that at least 20 OSC32K clock cycles elapse before calling MW_DiagClockCfd0End, because a missing CFD0 error flag may mean either that the measurement is not yet complete or that the injected fault was not detected.

Warning
This function backs up the current CFD0 configuration, CFD0 Error Channel configuration and CFD0 interrupt enable state, then applies temporary diagnostic configurations. Until

MW_DiagClockCfd0End is called, the CFD0 interrupt remains disabled and clock faults that CFD0 was configured to monitor before the diagnostic may not be detected. The original configurations are restored by MW_DiagClockCfd0End.

Note

This function disables global interrupts during its execution to ensure atomic execution and that accidental interrupts are not triggered by initiating the error injection.

Note

Error injection is not initiated if the Error Controller is not in NORMAL state, the CFD0 Error Channel is already set or a CFD0 diagnostic is already ongoing.

Return values
ERRORError injection did not start.
NO_ERRORCFD0 diagnostic successfully started.

◆ MW_DiagClockCfd0End()

errFlag_t MW_DiagClockCfd0End ( void )

Completes error injection diagnostic to detect faults in the Clock Failure Detection 0 (CFD0) monitor.

This function completes the CFD0 monitor diagnostic started by MW_DiagClockCfd0Begin. It evaluates whether the injected fault set both the CFD0 error flag and CFD0 Error Channel status, then restores the original CFD0 configuration, CFD0 Error Channel configuration and CFD0 interrupt enable state.

Warning

This function must only be called after at least 20 OSC32K clock cycles have elapsed since MW_DiagClockCfd0Begin. Calling this function too early may cause the diagnostic to report ERROR because the injected fault has not yet been detected.

Note

This function disables global interrupts during its execution to ensure atomic execution and that accidental interrupts are not triggered by finishing the error injection.

Note

If no CFD0 diagnostic is ongoing, this function does nothing and returns ERROR to avoid modifying the CFD0 configuration or CFD0 Error Channel configuration.

Return values
ERRORFault detected in the CFD0 monitor or diagnostic was not started.
NO_ERRORNo fault detected in the CFD0 monitor.

◆ MW_DiagClockCfm0()

errFlag_t MW_DiagClockCfm0 ( void )

Performs error injection diagnostic to detect faults in the Clock Frequency Measure 0 (CFM0) monitor.

This function performs a CFM0 monitor diagnostic by running measurements with different window configurations and evaluating the responses. The CFM0 Done flag must be set after the expected time has elapsed for each measurement. The diagnostic performs three checks:

  • Inside the window, expecting no CFM0 error flag or Error Channel status.
  • Above the window, expecting both the CFM0 error flag and Error Channel status.
  • Below the window, expecting both the CFM0 error flag and Error Channel status.
Warning

This function backs up the current CFM0 configuration and CFM0 Error Channel configuration, then applies temporary diagnostic configurations. Normal CFM0 faults may be masked during execution. The original configurations are restored before this function returns.

Note

This function disables global interrupts during its execution to ensure atomic execution and that accidental interrupts are not triggered by initiating the error injection.

Note

If the CFM0 reference clock stops while CPU execution continues, the CFM0 Done flag is not set. The diagnostic treats this as a failed measurement after a bounded delay, restores the saved configuration, and returns ERROR.

Note

The diagnostic is not started if the Error Controller is not in NORMAL state or the CFM0 Error Channel is already set.

Return values
ERRORFault detected in the CFM0 monitor or diagnostic did not start.
NO_ERRORNo fault detected in the CFM0 monitor.

◆ MW_StopCfd0()

void MW_StopCfd0 ( void )

Disables Clock Failure Detect 0 (CFD0).

This function disables CFD0 without changing its configuration. It is intended to be used before reconfiguration of CFD0 or entering Standby or Power-Down sleep modes.

During transitions into or out of sleep, the monitored clock source may be disabled or not yet stable. If CFD0 remains enabled during these transitions, a clock failure may be reported. Disabling CFD0 avoids spurious error reporting related to clock transitions.

Note
The Clock Failure Detected interrupt configuration is not modified.

void MW_StopCfm1 ( void )

Disables Clock Frequency Measure 1 (CFM1).

This function disables CFM1 without changing its configuration. It is intended to be used before reconfiguration of CFM1 or entering Standby or Power-Down sleep modes.

During transitions into or out of sleep, the monitored clock source may be disabled or not yet stable. If CFM1 remains enabled during these transitions, a clock frequency measurement error may be reported. Disabling CFM1 avoids spurious error reporting related to clock transitions.

Note
The Clock Frequency Measurement Error interrupt configuration is not modified.
