◆ T_ResetReasonExampleCallback()

void T_ResetReasonExampleCallback ( resetInfo_t resetInfo)

Placeholder implementation of a Handle Reset Reason callback function.

Note

The example implementation is intentionally left empty, as the appropriate handling is highly application specific and would require initialization of peripherals such as USART or a debug print interface before use.

This callback can be called by T_HandleResetReason for application-specific reset handling. Possible uses include:

  • Adding a debug breakpoint and watching the stored reset info variable during development
  • Sending the reset reason over a communication interface (e.g., USART, SPI, TWI)
  • Storing the reset reason to non-volatile memory (e.g., EEPROM) for later analysis
  • Triggering application-specific recovery or logging behavior

Parameters
resetInfoA structure containing the Reset Reason as determined in T_DetermineResetReason and the software reset Error ID as determined in EH_InitiateSafeState. The values are validated in T_HandleResetReason before the callback is called.
Warning

An application-specific Reset Reason handling callback should be implemented for proper reset handling.

Warning
Ensure that any hardware or software resources required by this callback for error recovery or diagnostics are fully initialized before this callback is invoked the first time. Refer to TM_Startup for startup sequencing details.
